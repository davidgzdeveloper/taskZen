# **App Name**: TaskZen

## Core Features:

- Kanban Board: Kanban board with drag-and-drop functionality for managing tasks in 'To Do', 'In Progress', and 'Done' columns, with real-time synchronization with Firestore.
- Pomodoro Timer: Pomodoro timer with customizable work and break durations, session type indicator, and browser notifications.
- Scoring System: Simple scoring system that calculates points based on task priority and pomodoro completion.
- Dashboard: Dashboard for displaying stats, including tasks completed, pomodoros completed, current streak, and total score, along with simple charts.
- Authentication: Authentication module with sign-in using Google, email/password, and anonymous access, with protected routes using React Router.
- AI Task Optimizer: AI-powered task prioritization tool to analyze the tasks using task details, considering the user's working patterns, and recommend the best priority for each task, re-ranking and re-prioritizing if needed.

## Style Guidelines:

- Primary color: A calm, productive blue (#468B97) for focus and clarity.
- Background color: Soft, desaturated off-white (#F0F4F5).
- Accent color: Complementary sandy yellow (#E0C271) to highlight key elements and actions.
- Body and headline font: 'Inter', a sans-serif font known for its legibility and neutral appearance, suitable for both headlines and body text.
- Minimalist, consistent icons to represent task priorities, status, and settings.
- Responsive layout with a collapsible sidebar for easy navigation on both desktop and mobile devices.
- Subtle transitions and animations for task completion and score updates to provide engaging feedback.
